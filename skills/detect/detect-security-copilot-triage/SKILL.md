## When to use

- When agent alert volume exceeds the SOC manual triage capacity
- To standardize the agentic incident triage process across analysts with different experience levels
- As a first-line response to jailbreak alerts or agent anomalies
- To generate executive summaries of agentic incidents for CISO escalation

## Prerequisites

- Microsoft Security Copilot active in the tenant
- Connection to Microsoft Sentinel configured in Security Copilot Sources
- Connection to Microsoft Defender XDR configured in Security Copilot Sources
- Minimum Security Operator role for the analyst

## Workflow

### Step 1 — Configure the data sources in Security Copilot

In **Security Copilot** → **Sources** → verify these are active:
- ✅ Microsoft Sentinel (agent security workspace)
- ✅ Microsoft Defender XDR
- ✅ Microsoft Entra (for agent identity context)
- ✅ Microsoft Purview (for sensitive data context)

### Step 2 — Jailbreak triage prompt

```
Analyze the Sentinel incident with ID {INCIDENT_ID}.

1. What is the incident's severity and title?
2. Which AI agent is involved? (name, type, platform, technical owner)
3. What are the incident's indicators of compromise?
4. Search Defender XDR for related activity from the same user or IP in the last 4 hours
5. Assess: is this a real jailbreak attempt (high confidence), likely (medium), or a false positive (low)?
6. If high or medium confidence: which permissions does the agent hold that could be exploited?
7. Recommend: contain now (revoke token) or monitor for 30 more minutes
```

### Step 3 — Executive summary prompt for escalation

```
Based on Sentinel incident {INCIDENT_ID} and your prior analysis:

Generate an executive summary of at most 150 words that includes:
- What happened (in business language, no technical jargon)
- Which agent was involved and what function it serves in the organization
- What data or systems were at risk
- What action the SOC team took and when
- Whether there is confirmed data exposure or only potential risk
- Recommended next step for leadership

Audience: CISO and Director of Operations. Do not use acronyms without explanation.
```

### Step 4 — Historical pattern analysis prompt

```
In Microsoft Sentinel, find every incident from the last 90 days that:
- Involves AI agents (search title for: "agent", "copilot", "AI", "jailbreak")
- Has severity High or Critical

For each group of similar incidents, determine:
1. How many incidents of the same type are there?
2. Is there an agent that appears across multiple incidents?
3. Is there a time-of-day or user pattern?
4. How many were closed as false positives vs. confirmed?

Identify the top 3 most frequent attack patterns and the top 3 most involved agents.
```

### Step 5 — Measure agentic triage impact

```kql
// Compare MTTD before and after enabling Security Copilot for triage
SecurityIncident
| where TimeGenerated > ago(180d)
| where Title has_any ("Agentic AI", "jailbreak", "agent")
| extend CopilotEnabled = TimeGenerated > datetime(2024-06-01) // adjust to activation date
| extend TimeToTriage_hours = datetime_diff('hour', TimeGenerated, CreatedTime)
| summarize
    AvgTimeToTriage = avg(TimeToTriage_hours),
    P90TimeToTriage = percentile(TimeToTriage_hours, 90),
    IncidentCount = count()
    by CopilotEnabled
```

## Verification

- [ ] Security Copilot connected to Sentinel, Defender, Entra, and Purview
- [ ] Jailbreak triage prompt run against a real or test incident
- [ ] Executive summary generated and validated by a senior analyst
- [ ] The historical pattern prompt returns results consistent with tenant incidents
- [ ] MTTD baseline established to measure agentic triage impact

## Implementation notes

- Security Copilot accesses connected source data in real time — triage quality depends on those connections being healthy
- Triage prompts must be reviewed periodically: jailbreak patterns evolve and generic prompts produce degraded results
- Security Copilot cannot execute containment actions directly (revoke tokens, block an SP) — it always requires a human
- Combine with `detect-sentinel-mcp-server` for the full flow: Security Copilot queries Sentinel via MCP and updates the incident
